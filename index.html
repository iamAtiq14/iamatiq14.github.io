FLAGSHIP ENTERPRISE CASE STUDY

ABIS — National Automated Biometric Identification System

TechoStudios Pvt Ltd (Consult First IM&T - UK) · Client: Black Ocean Safi Group / MOI & NSIA · August 2025 — Present

Throughput Benchmark ~23K records/hour

The National Platform Architecture

ABIS is a government-grade biometric identity platform engineered for national civil registry and law-enforcement identity programs. It delivers 1:1 verification and 1:N deduplication across massive resident populations:

  • Multi-Modal Biometrics: Captures and processes fingerprint (10-print slaps & rolls), facial recognition, dual iris, and palm print data streams.
  • Distributed Architecture: Decoupled backend powered by AABIS.WebApi (.NET 8 REST API), dedicated biometric extraction microservices, and specialized WPF desktop clients.
  • Automated Deduplication Engine: Interfaces with high-performance MegaMatcher Accelerator clusters with algorithmic deduplication policy matching.
  • EFT & ANTemplate Standards: Native parsing and packaging of ANSI/NIST-ITL electronic fingerprint transmission files for multi-agency interoperability.
  • Enterprise Data Tier: Authoritative PostgreSQL data store with partitioned tables, optimized indexes, and S3-compatible object storage for high-resolution biometric imagery.

My Personal Engineering Deliverables

As a .NET Engineer on the platform engineering team, my core contributions focused on backend services, desktop operator modules, and database optimization:

  • Core REST API Engineering: Built and enhanced ASP.NET Core 8 Web API endpoints in AABIS.WebApi supporting enrollment submission, search, verification, and reporting.
  • WPF Desktop Application Modules: Developed and maintained offline-capable operator workstation modules in AABIS.User using XAML and the MVVM architecture for biometric capture and review screens.
  • PostgreSQL Schema & Query Tuning: Designed normalized schemas, created high-performance stored procedures, and applied indexes to accelerate multi-field resident searches.
  • EFT Interchange & SignalR Feeds: Implemented EFT/ANTemplate import-export routines and integrated real-time processing status updates via SignalR.
  • Production Issue Ownership: Investigated and resolved production bottlenecks, edge cases in offline data caching, and ensured reliable deployments in an Agile workflow.
